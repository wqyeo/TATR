TATR 0.1.0a is the first experimental alpha of That's Another Task Runner.

TATR runs TOML-defined argument arrays sequentially, resolves dependencies once,
and stops at the first failure. It supports task working directories, child-only
environment overrides, explicit dotenv files, literal target runtime arguments,
and console action logging with optional append-only log files.

Downloads:

- **Windows x64/MSVC ZIP**: static MSVC runtime; imports KERNEL32.dll.
- **Alpine Linux 3.21 x64/musl tar.gz**: requires libstdc++.so.6, libgcc_s.so.1 and
  libc.musl-x86_64.so.1. This is not a universal Linux/glibc binary.
- **SHA256SUMS**: SHA-256 hashes of both archives.

Extract the entire archive and run `bin/tatr --version` (Windows:
`.\bin\tatr.exe --version`). Each archive includes a usage guide, build/file-hash
manifest, sample TOML/public dotenv file, and both required MIT notices.
The optional sample uses CMake 3.25+; TATR itself needs no compiler or CMake to
run arbitrary workflows. Keep both license notices when redistributing.

Verification: Windows/MSVC strict build and 341 tests; Alpine/GCC strict build and
332 tests. Each archive was extracted into a spaced path and its contents checked
against staging. Extracted help/version/list/plan/task execution, explicit dotenv
loading and console/file logging passed on the corresponding tested platform.
The earlier code baseline also passed Clang analysis and ASan/UBSan checks; those
are not claims of safety proof or support for other systems.

Known alpha limits: macOS, glibc Linux, MinGW, older OS/compiler versions and other
architectures are unverified. No implicit shell, timeout/process-tree cleanup,
parallel execution, caching, child-output capture or log rotation/retention.
Child stdout/stderr remain on the console. Task names and error paths can disclose
project metadata. Logging/configuration interfaces may change during development.

See the tagged README and docs/configuration.md for the full CLI/TOML contract.
