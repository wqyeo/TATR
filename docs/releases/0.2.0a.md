TATR 0.2.0a adds deployment completion hooks, structured SMTP email actions and a
Debian/glibc package to the minimal TOML task runner.

New since 0.1.0a:

- Success/failure/always completion hooks with target filters, original-run context,
  declaration ordering and explicit warn/fail policies. Ordinary tasks remain fail-fast.
- SMTP actions in tasks or hooks: UTF-8 plain-text MIME messages, dotenv/environment
  authentication, required verified STARTTLS/SMTPS, optional private CA trust,
  bounded input, private stdin and scoped temporary message files. An external
  native curl 8.0+ with SMTP/SMTPS/TLS is required only for SMTP actions; no client
  or SMTP/TLS library is bundled. Server acceptance does not guarantee inbox delivery.
- Debian 12 x64/glibc 2.36 archive alongside Windows/MSVC and Alpine/musl packages.
- A leaner README, Keep a Changelog file, and opt-in Node.js/PHP, file/archive and
  database backup/restore workflow examples and verification evidence.

Downloads:

- **Windows x64/MSVC ZIP**: static MSVC runtime; requires Windows system ACL and
  synchronization APIs (KERNEL32.dll, ADVAPI32.dll, api-ms-win-core-synch-l1-2-0.dll).
- **Alpine Linux 3.21 x64/musl tar.gz**: compatible musl, libstdc++ and libgcc runtimes.
- **Debian 12 x64/glibc tar.gz**: glibc 2.36 build baseline, libstdc++ and libgcc.
  Other glibc baselines remain unverified; this is not a universal Linux binary.
- **SHA256SUMS**: SHA-256 hashes of all three archives.

Extract the entire archive; run bin/tatr --version (Windows: .\bin\tatr.exe --version)
or add bin to PATH. Archives include a usage guide, changelog, source/file-hash
manifest, public dotenv/hook/SMTP examples and both MIT license notices. Keep
those notices when redistributing. CMake is only needed for demonstration tasks.
Configure SMTP addresses and private credentials before sending; list/plan can
inspect the examples without credentials, curl or a mail server.

Verification: Windows strict 442/442 tests; Debian/GCC 431/431; Alpine/Clang
formatting/static analysis and 431/431; ASan/UBSan 433/433. Detailed environments
are in docs/verification.md. Extracted Windows and Alpine release binaries each
passed 13 local SMTP/TLS cases. Debian's archive passed its own baseline regression
and extracted command/hook checks; live transport coverage is Windows and Alpine. Extracted packages verify exact contents,
help/version, task planning/execution, dotenv/logging and success/failure hooks.
Local SMTP/TLS fixtures exercise authentication, both TLS modes, rejection,
certificate verification, timeouts and hook policies without real recipient delivery.

Alpha limits: macOS, other architectures and older OS baselines are unverified.
No implicit shell, parallel execution, caching, general command timeout,
process-tree cleanup, child-output capture or log rotation/retention. SMTP sending
has curl transport timeouts but no retry/spool, OAuth, HTML or attachments. Direct
command output remains inherited; SMTP-client output is suppressed. Crashes or
interruption can prevent hooks and leave private temporary files. CLI/configuration
interfaces may change during alpha development.

See CHANGELOG.md, docs/configuration.md, docs/completion-hooks.md and docs/smtp.md
at the signed 0.2.0a tag. The existing 0.1.0a release remains unchanged.
